# Triage Playbook: Suspicious Encoded PowerShell Execution (T1059.001)

## 1. Overview
* **Technique ID:** T1059.001 (Command and Scripting Interpreter: PowerShell)
* **Severity:** High
* **Objective:** Detect and investigate obfuscated or base64-encoded PowerShell commands designed to bypass security controls.

## 2. Initial Triage Steps
When this alert fires, the SOC analyst should immediately examine the following fields in the SIEM:
1. **Parent Process:** Was PowerShell spawned by an unexpected application (e.g., `winword.exe`, `excel.exe`, `cmd.exe`, or `lsass.exe`)?
2. **Command Line Arguments:** Look for flags like `-enc`, `-EncodedCommand`, `-e`, or execution policies bypassed (`-ExecutionPolicy Bypass`).
3. **User Account:** Is the process running under a standard user account, a service account, or a high-privilege domain administrator?

## 3. Payload Extraction & Decoding
1. Copy the long base64 string found in the command line argument.
2. Open **CyberChef** (or your local decoding tool).
3. Input the base64 string and apply the **From Base64** recipe.
4. *Note:* If the output text is formatted in UTF-16LE (common for PowerShell), add the **Deselect / Decode text** or character set modifier to read the actual script block safely.

## 4. Containment & Remediation
* **Isolate Host:** If the decoded command reveals malicious network downloads (e.g., `Invoke-WebRequest`, `IEX`), immediately isolate the host from the network.
* **Kill Process:** Terminate the suspicious PowerShell PID.
* **Escalate:** Create an incident ticket for Tier 2/Threat Response.
